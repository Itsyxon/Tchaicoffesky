# Кофейня «Чайкоффский»

Проект по разработке многостраничного сайта на React с использованием технологий:

- Next.js
- TypeScript
- React
- Tailwind CSS

## Установка и запуск

1. Клонирование репозитория

   `git clone https://github.com/Itsyxon/Tchaicoffesky`

2. Установка зависимостей
   
   `npm install`

3. Сборка приложения
   
   `npm run dev`

4. Приложение доступно по адресу
   
   `localhost:3000`

### О проекте

Многостраничный сайт кофейни на Next.js: главная, меню с фильтрами и поиском, страницы «О кофейне» и «Контакты».

### API

Список напитков отдают route handlers, меню ходит за данными к ним.

`GET /api/products` — список позиций.

| Параметр   | Значение                | Описание                                  |
| ---------- | ----------------------- | ----------------------------------------- |
| `category` | `coffee`, `tea`, `food`, `all` | Фильтр по категории, по умолчанию `all` |
| `q`        | строка                  | Поиск по названию, описанию и вкусу       |
| `limit`    | положительное число     | Сколько позиций вернуть                   |

Ответ: `{ items, total, category, query }`. Неизвестная категория — `400`.

`GET /api/products/:id` — одна позиция по числовому `id` или по `slug`, например `/api/products/flat-white`. Если позиции нет — `404`.

### Структура проекта

`public`

Папка для изображений/иконок

`src/`

Главная рабочая директория

`src/components/`

Содержит React-компоненты

`src/app/`

Содержит страницы приложения (роутинг)

`src/data/`

Содержит локальные данные: карточки напитков и контакты кофейни

`src/lib/`

Выборка и фильтрация напитков, которой пользуются страницы и API

`src/app/api/`

Route handlers для получения списка напитков

`src/app/global.css`

Содержит глобальные стили

`src/app/page.tsx`

Главная страница сайта
